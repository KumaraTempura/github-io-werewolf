# 狼人殺法官筆記

A single-device, judge-operated notebook for Werewolf (狼人殺).

## Development

```sh
npm install
npm run dev
npm test
npm run build
```

## Deployment

Pushes to `main` deploy the production build to GitHub Pages via
`.github/workflows/deploy.yml`.

Live site: https://kumaratempura.github.io/github-io-werewolf/
